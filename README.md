# Portfolio SEG3525

Ce projet est un portfolio personnel créé dans le cadre du cours SEG3525.

## Technologies utilisées

- HTML
- CSS
- Bootstrap
- JavaScript

## Style visuel

### Palette de couleurs

- #071013 — Ink Black
- #55F1F1 — Neon Ice
- #1E2328 — Carbon Black
- #6B7380 — Slate Grey
- #FFFFFF — White

### Typographie

- Police principale: Arial
- Style moderne et minimaliste
- Grande hiérarchie visuelle pour mettre en valeur les sections importantes

## Contenu

- Présentation personnelle
- Section sur ma façon de travailler
- Liens vers les futurs projets du semestre:
  - Site de service
  - Jeu de mémoire
  - Site e-commerce
  - Site de visualisation de données

## Fonctionnalités

- Navbar verticale avec effet glassmorphism
- Mode sombre/mode clair

## Hébergement

Le site est hébergé sur Vercel.
